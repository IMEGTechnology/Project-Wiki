Clipboard inspector

Shows the exact HTML an app put on the clipboard. Nothing is sent anywhere; this page has no network access of any kind.

  1. In OneNote, type a three-level bulleted list. The one you already know pastes into Forma correctly.
  2. Select it and copy it.
  3. Click the dashed box below and press Ctrl+V.
  4. Press Copy the result and paste that into the chat.
