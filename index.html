Passwords

          

            
            
          

          

        

        
        

          Locked out? The passwords are SHA-256 hashes in
          zSystem/auth.json in the vault. Delete that file in Obsidian
          or in SharePoint and every tier opens again with no prompt, the same as a
          vault that was never set up. Come back to this tab, switch to
          Administrator and set both passwords again. Anyone who can be locked out
          already has the vault access needed to undo it.
